# Dashboard de Control Operativo y KPIs en Power BI

## Descripción
Diseño e implementación de un modelo de datos en estrella (Data Mart) y tablero interactivo en Power BI para el seguimiento de efectividad operativa, cumplimiento de SLAs y costos por proceso.

## Incluye
- Scripts DAX para métricas acumuladas y Time Intelligence.
- Modelo relacional optimizado en Power Query.
