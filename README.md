## 📁 Proyectos Destacados

### 1. [Detección de Fraude Financiero con Machine Learning](./proyectos/01-deteccion-fraude-ml)
- **Enfoque:** Algoritmo supervisado para identificación de transacciones anómalas en tiempo real con datos desbalanceados.
- **Impacto:** Reducción del 34% en falsos positivos y detección oportuna de patrones fraudulentos.

### 2. [Dashboard de BI & Process Mining Operativo](./proyectos/02-dashboard-bi-operativo)
- **Enfoque:** Tablero interactivo en Power BI para control de KPIs, tiempos de ciclo y eficiencia en la cadena de valor.
- **Impacto:** Automatización total de reportes e identificación de demoras operativas en +25%.

### 3. [Modelamiento Predictivo de Cuellos de Botella](./proyectos/03-optimizacion-procesos-predictivo)
- **Enfoque:** Modelo de regresión/clasificación para predecir saturación en flujos de trabajo y reingeniería de procesos.
- **Impacto:** Optimización del tiempo de respuesta global en un 42%.
